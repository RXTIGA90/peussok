AMD FidelityFX SDK 1.1.4 (FSR 3 optical flow + frame interpolation): MIT, Copyright (C) 2024

https://github.com/GPUOpen-LibrariesAndSDKs/FidelityFX-SDK tag v1.1.4. Compiled into the engine DLL
(Vulkan backend only). Local changes: scratch arrays aligned to 16 bytes in ffx_vk.cpp (the
original 4-byte alignment crashes under clang's aligned SSE moves); swapchain hook stubbed; GLSL
shaders compiled with glslang 11.9 without the SPIR-V optimizer. Video input has no depth or game
motion vectors, so FSR 3 runs on its own optical flow only.
Not sponsored or endorsed by AMD.

1.6.0 modifications to rife-ncnn-vulkan (MIT): pre/post-processing shaders take the bytes per
pixel as a specialization constant (BGRA frames without CPU conversion). Above 1920x1080 the
RIFE 4.6 flow network runs on half-size images and a weight-free tail network resizes the flow
and mask to full size and warps/blends the full-size images (the reference RIFE scale=0.5
inference; 2.2.6: the final flow and mask are found by graph structure, so RIFE 4.15 lite
uses the same path). The model files stay unmodified and SHA256-pinned; the network description is
rewritten in memory after the pinned file is verified.

python, documentation) are left out of this repository.
