프쏙 (PEUSSOK) 1.0.0 사용 설명서

프쏙은 캡처카드로 받은 게임기 화면을 더 부드럽게 보여 주는 프로그램이에요.
원본 화면 두 장 사이에 새 화면을 만들어 넣어서, 30fps 게임은 60fps(또는 그 이상)처럼 보여요.
방송·녹화 프로그램을 따로 켤 필요가 없어요.

왼쪽 아래 "사용 가이드" 버튼을 누르면 화면을 하나씩 짚어 가며 알려 줘요.


■ 처음 시작하기

1. 게임기 → 캡처카드 → PC를 연결하고 게임기를 켜세요.
2. 캡처카드를 쓰는 다른 프로그램(방송·녹화 프로그램 등)은 꺼 주세요. 같이 켜 두면 화면이 늦게 올 수 있어요.
3. 프쏙을 실행하세요.
4. 화면이 안 나오면 왼쪽 "입력" 탭에서 캡처카드를 고르세요.
5. 홈의 가운데 원을 눌러 프레임 생성을 켜세요.
6. "전체 화면으로 시작"을 누르고 게임을 하세요. 전체 화면이 반응이 가장 빨라요.


■ 홈 화면

가운데 원       누르면 프레임 생성이 켜지고 꺼져요. 지금 보이는 fps와 원본 fps가 나와요.
프리셋 네 가지  초저지연 · 저지연 · 균형 · 화질 우선
                - 처음에는 "균형"을 쓰세요.
                - 슈팅·격투처럼 반응이 중요하면 "초저지연"
                - 영화처럼 부드러운 움직임이 좋으면 "화질 우선"
모델            새 화면을 만드는 방법이에요. "추천"이 붙은 모델을 쓰세요.
                - NVIDIA VFG: 화질이 가장 좋아요. 처음 고를 때 NVIDIA 파일(약 416 MB)을 받아요.
                - RIFE 4.6 / RIFE 4.15 lite: 화질이 좋고 대부분의 그래픽카드에서 돼요.
                - NVIDIA DLSS FG: 빨라요.
                - FSR 3 / AMD FSR FG: 가벼워요. 느린 컴퓨터용이에요.
배수            원본 한 장을 몇 장으로 늘릴지예요. 30fps 게임은 2배면 60fps, 4배면 120fps.
                모니터가 보여 줄 수 있는 주사율(Hz)을 넘지 않게 고르세요.
DLSS 5          게임 화면을 실사 느낌으로 바꿔요(아래 "DLSS 5" 참고).
내 컴퓨터에 맞는 설정 찾기
                내 컴퓨터에서 잘 도는 모델과 배수를 찾아 줘요. 처음에 한 번 해 보세요.


■ 왼쪽 탭

생성     프레임 생성 켜기, 모델, 배수
         지연: 만든 화면을 보여 주는 시간, 여유 시간, 선행 생성
         만든 화면 보호: HUD 보호 · 글자 보호(켜 두세요), 얼굴·움직임 보호, 장면 전환 감지
화질     선명도, 색 범위(검은색이 뜨거나 뭉개지면 바꿔 보세요), DLSS 5
화면     전체 화면/창, 화면 채우기
         동기화: 화면 동기화(수직·가변·끔), G-SYNC·FreeSync
         HDR 모니터 출력
         게임 화면 위 정보(fps·지연 표시)와 위치, 모니터 꺼지지 않게
입력     캡처카드, 디코드 형식, 해상도, 초당 장수. 보통은 모두 "자동"이 가장 좋아요.
         아래 "입력 신호"에서 카드가 실제로 보내는 화면을 확인할 수 있어요.
소리     소리 크기, 캡처카드 소리 켜기, 소리 늦추기
         소리가 화면보다 먼저 들리면 "화면 지연에 맞추기"를 누르세요.
녹화     녹화 시작·멈추기, 담을 화면(보이는 그대로/원본만), 코덱, 화질, 소리, 저장 폴더
데이터   fps, 지연, 그래픽카드 사용량 같은 숫자를 화면 옆에 보여 줘요.
테마     색과 배경 그림
벤치마크 내 컴퓨터에 맞는 설정 찾기
설정     언어, 창 모양, 켤 때 동작, 단축키, 처음 설정으로 되돌리기

탭마다 위쪽의 "기본값으로"를 두 번 누르면 그 탭의 설정만 처음 값으로 돌아가요.


■ 녹화

위쪽 녹화 버튼(전체 화면 버튼 옆)이나 Ctrl+Alt+R을 누르면 녹화가 시작돼요. 다시 누르면 멈춰요.
보이는 화면 그대로(만든 화면 포함) 캡처카드 소리와 함께 MP4로 저장해요.
그래픽카드의 영상 인코더를 써서 게임 반응에는 영향이 없어요.
파일은 "동영상\Peussok" 폴더에 생겨요. 녹화 탭에서 폴더를 바꿀 수 있어요.


■ DLSS 5

NVIDIA의 뉴럴 렌더링으로 게임 화면을 실사 느낌으로 바꿔요.
필요한 것: RTX 50 그래픽카드, 최신 NVIDIA 드라이버, 그리고 DLSS 5를 쓰는 게임이 이 PC에 설치되어 있어야 해요.
  DLSS 5 파일은 NVIDIA 것이라 프쏙에 넣을 수 없어요. 프쏙이 설치된 게임에서 자동으로 찾아요.
  못 찾으면 화질 탭의 "파일 고르기"로 직접 고를 수 있어요(NVIDIA가 서명한 파일만 써요).
강도는 1~5단계예요. 높을수록 더 진해지고 조금 더 무거워져요.
얼굴이 거칠어 보이면 "피부 부드럽게"를 올리세요. 질감이 떨려 보이면 "깜빡임 억제"를 올리세요.


■ 반응을 빠르게 쓰려면

- 전체 화면으로 쓰세요. 창으로 쓰면 반응이 조금 느려져요.
- 모니터와 그래픽카드 설정에서 가변 주사율(G-SYNC·FreeSync)을 켜고, 화면 탭의 화면 동기화를 "가변"으로 두세요.
  화면이 찢어져 보이면 "수직"으로 바꾸세요(아주 조금 느려져요).
- 홈의 "초저지연"을 고르세요.
- 캡처카드를 쓰는 다른 프로그램을 꺼 두세요.


■ 단축키

F11, Alt+Enter, 화면 더블클릭   전체 화면 켜고 끄기
Esc                            가이드·설정 닫기, 전체 화면 끝내기
F1, 마우스 오른쪽              설정 열기
Ctrl+Alt+G                     프레임 생성 켜고 끄기 (다른 창에서도 돼요. 설정에서 바꿀 수 있어요)
G                              프레임 생성 켜고 끄기 (프쏙 창에서)
Ctrl+Alt+R                     녹화 시작·멈추기
M                              음소거
위·아래 화살표                 소리 크기


■ 이럴 때는

화면이 안 나와요
  - 입력 탭에서 캡처카드를 다시 고르고 "카드 다시 찾기"를 눌러 보세요.
  - 다른 프로그램이 캡처카드를 쓰고 있으면 꺼 주세요.
  - 게임기에서 HDCP를 꺼 주세요. HDCP가 켜진 화면은 캡처카드가 넘겨주지 않아요.
화면이 깨지거나 번져 보여요
  - 모델을 "추천"이 붙은 것으로 바꾸세요.
  - 생성 탭의 HUD 보호·글자 보호가 켜져 있는지 확인하세요.
화면이 끊겨요
  - 배수를 낮추거나 "내 컴퓨터에 맞는 설정 찾기"를 해 보세요.
  - 입력 탭의 "입력 신호"에서 카드가 실제로 보내는 장수를 확인하세요.
    값싼 USB 캡처카드는 초당 30장만 보내기도 해요. 이때도 2배로 60fps가 돼요.
색이 이상하거나 물빠져 보여요
  - 게임기에서 HDR을 켰다면 화면 탭의 "게임기 HDR 받기"를 켜 주세요. 캡처카드가 바꿔 준 화면을 10비트로 받아서 색이 원본과 같고 하늘 같은 곳의 계단이 줄어요.
  - 검은색이 회색으로 보이면 화질 탭의 "색 범위"를 바꿔 보세요.
소리가 안 나요
  - 소리 탭에서 "캡처카드 소리 켜기"와 "받는 소리"를 확인하세요.
프로그램이 멈췄어요
  - 프쏙이 스스로 다시 켜고, 같은 모델이 또 멈추면 다른 모델로 바꿔요.


■ 그 밖에

필요한 것: 윈도우 10/11 64비트, 캡처카드, DirectX 11과 Vulkan을 쓰는 그래픽카드
설정과 기록이 저장되는 곳: %LOCALAPPDATA%\Peussok (포터블 버전은 프로그램 폴더의 data)
NVIDIA VFG 파일은 처음 고를 때 동의하면 NVIDIA 공식 서버에서만 받아요. 그 밖에 인터넷으로 보내거나 받는 것은 없어요.
캡처카드 제조사와 관계없는 개인 프로그램이에요.
